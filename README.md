# Capstone-Project
COTS Monitor is a machine learning and GIS-based system that detects, counts, and maps Crown-of-Thorns Starfish (COTS) using GoPro underwater images. It provides monitoring, validation, alerts, analytics, and reports to support coral reef conservation.
COTS Monitor is a machine learning and GIS-based system designed to support the detection, counting, mapping, and monitoring of Crown-of-Thorns Starfish (COTS) in coral reef environments. The system uses underwater images captured through GoPro cameras, which are uploaded together with relevant monitoring information such as GPS location, date, time, and reef zone. The uploaded images are processed using image preprocessing techniques and a YOLO-based machine learning model to identify and count COTS and provide confidence scores for the detected objects. The system also uses GIS technology to visualize COTS detection locations, monitor affected reef zones, and identify areas with different levels of infestation. In addition, COTS Monitor provides features for detection validation, removal evidence submission and verification, alerts, analytics, and report generation. By integrating underwater imaging, machine learning, GIS mapping, and centralized data management, the system aims to provide a more organized and efficient approach to COTS monitoring and support informed decision-making for coral reef conservation and management.
